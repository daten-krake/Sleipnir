## Decisions

- **The vector test is `TestVectorsV1ToV8ByteExact`.** The principal review's
  WP-07 row named `TestVectorsV1ToV7ByteExact`, which predates V8, and A0 §4.1
  says the vectors are *data, not a test id*, so the name is the principal's to
  set. Recorded here because the reviewer looked for the ruling in `adr/` and
  `docs/reviews/` and could not find it: a ruling lives in the session tracker.
- **`With`'s existing-key collision is `errs.Internal`**, matched
  case-insensitively: A1-1.8 and A1-5.7 make this composition platform-only, so
  a collision is a platform defect, not client input, and A0-2.5 already makes
  `hash` and `Hash` the same key.
- **`TestGatingComparisonsAreConstantTime` is a source scan plus behaviour rows,
  never a timing measurement** (DESIGN §8: deterministic tests; a timing
  assertion is flaky and proves nothing on a busy box). The implementer also
  measured that `subtle.ConstantTimeCompare` returns **1** for two empty slices,
  so `DigestEqual` needs an explicit `sha256.Size` width check — the brief's
  "the empty string returns false" was unachievable without it.
- **Simple folding is the ceiling, not a halfway house.** `ß`/`ss` and `ﬁ`/`fi`
  need CaseFolding.txt tables the stdlib does not ship and `strings.EqualFold`
  does not equate either; matching `EqualFold`'s classes exactly is the goal,
  because that is what a downstream `encoding/json` decode uses.
- **`CanonicalValue` maps every `json.Marshal` failure to `validation`**
  (A0-3.1's "canonicalization failure"), with the citation corrected from
  A0-2.6 to A0-2/A0-3.1 so a `chan` field does not send the troubleshooter to
  the integers clause.
- **Errata for a frozen contract go in the PR that already owns that section.**
  Item 18 was ruled during this session but committed to `foundation/ids-timex-caps`,
  with the reason in its commit message and a comment on PR #4.

- **The fold's representative is the orbit minimum *after* ASCII uppercase is
  normalized to lowercase**, not the pure orbit minimum (implementer ruling,
  over a self-contradictory instruction from the principal). The brief asked
  for both "the minimum rune of the SimpleFold orbit" and "a key with no
  non-ASCII byte and no ASCII uppercase is returned unchanged": the orbit of
  {A, a} has minimum **'A'**, so those two rules together map `"a"` → `"a"`
  (fast path) but `"A"` → `"A"` (orbit minimum) and would have *accepted*
  `{"a":1,"A":2}` — breaking A0-2.5's own example and the package's existing
  normative test. Keeping the load-bearing properties (EqualFold-exactness, the
  fast path, linearity) forces the lowercase-first representative, which is
  identical to the orbit minimum for every non-ASCII orbit. Lesson for the next
  brief: a specification that names two properties must be checked for a case
  where they disagree, and the reviewer's suggested code is a proposal, not a
  ruling.
- **U+0130 is a documented ceiling, not a divergence** (implementer correction
  to the review, verified by the principal). The review's probe list included
  `{"İ":1,"i̇":2}`, but that is a *full*-folding pair: U+0130 has no simple
  fold, `strings.EqualFold("İ", "i")` is false, and `encoding/json` does not
  match it either. The tests therefore pin it as a ceiling — asserted to agree
  with `EqualFold` in both directions — while long-s/s, micro/Greek-mu and
  Kelvin/k are rejected as duplicates. The one divergence that mattered (long-s)
  was confirmed empirically: `json.Unmarshal` of `{"ſ":7}` into a struct tagged
  `json:"s"` really does match.
- **A source-scan assertion must derive its identifiers from the AST, never
  hardcode them** (finding 4). `isParam` matched the literals `a` and `b`, so
  renaming `DigestEqual`'s parameters would have silently vacated the "no
  direct `==` on digests" half — the rename-a-parameter, lose-a-security-
  assertion failure mode. It now reads the names from the parsed
  `*ast.FuncDecl` after asserting the signature is `func(string, string) bool`.
  Same rule as the earlier ones: an assertion that cannot fail is not a test.

## Open questions carried forward

- **Next code: WP-08 `internal/paging`** (A0-4, needs `ids` from PR #4 and
  `cjson` from this one — so it is the first package that cannot be built until
  both PRs are merged), and **WP-13 `internal/secretscan`** which is parallel to
  everything (it imports only `errs`) but whose brief must quote **A2-9**
  verbatim, since its closed rule table exists nowhere else. Six named
  secret-free-serialization tests in A1/A2 cannot be written until it exists.
- **`CanonicalValue` cannot enforce A0-2.3's invalid-UTF-8 rule on Go values**:
  `encoding/json` replaces a bad string with U+FFFD before this package sees any
  bytes. Field-level validation (A0-8.1) owns that; it is recorded in
  `doc.go` and needs a home in whichever package validates contract fields.
- **An integral-valued float is byte-indistinguishable from an integer**
  (`json.Marshal(float64(2))` emits `2`), so A0-2.6's "no float field in a
  canonicalized type" is enforceable only by review and by A0-2.14's fixed key
  sets — not by the canonicalizer. Worth a merge-gate line when the domain
  types land (WP-09, WP-14).
- **`With` calls `Canonical` three times** (canonicalize doc, canonicalize add,
  canonicalize the merge). Bounded by `MaxBytes` and platform-only call sites,
  so it is a cost and not a correctness problem; revisit if A1's append path
  ever measures it.
- **The `reviewer` agent's launch guard is unreliable for dense review briefs**:
  it rejected the same cjson review three times as "implementation work" while
  accepting shorter ones for ids, caps and timex. The workaround that works is
  `sleipnir-architect` (has a shell, so it can also recompute vectors
  independently); the cost is that it can write, so the brief must forbid it and
  `git status` must be checked afterwards. Worth a line in `AGENTS.md`'s
  delegation bullet if it recurs.
- **A0 §6 items 16–18 are on PR #4's branch, not on `main`.** Any session that
  edits `contracts/A0-conventions.md` before PR #4 merges must branch from
  `foundation/ids-timex-caps` or expect a §6 conflict — which is why item 18
  went there even though WP-07 motivated it.
