  4 files, 1830 lines — the §4 sketch's surface exactly (`MaxDepth`, `MaxBytes`,

  else exported. **18 top-level test ids, exactly the required set**, 163
  subtests, all eight A0-2.17 vectors byte-exact against the published bytes,
  `len` and SHA-256 columns, all 21 rejection-list rows (in table order) plus 13
  extras, both accept cases, 95.7% statement coverage. Gates green

  `go.mod` untouched at zero requires.
- **Principal audit before trusting the report** (the 2026-09-11 lesson): all
  eight vector fixtures compared by hand against the A0-2.17 table (digests and
  lens), the rejection table counted (21 contract rows + 13 extras), the test
  file proven free of raw U+2028/9/7F bytes (fixtures use Go escapes, so it
  stays greppable), and the whole 543-line canonicalizer plus `digest.go` read.
  Confirmed: `-0` is rejected before the regex that would accept it, the
  accepted number literal is re-emitted verbatim, keys sort by Go string order
  (= unsigned UTF-8 byte order, V6's point), exclusion happens *after*
  validation so a malformed or duplicate key cannot hide behind an excluded
  name, `requireEnd` checks the unread bytes because `More()` returns false for
  `{"a":1}}`, and every decoder error maps to `errs.Validation`.
- **Independent review** by `sleipnir-architect` (it has a shell; the builtin
  `reviewer`'s launch guard rejected the same task twice as "implementation
  work", and its earlier no-shell lanes cost one report to a `find /` hang).
  It recomputed all eight vectors from the contract table in Python — 8/8 on
  `len` and digest — and separately re-parsed the test's Go literals with its
  own decoder, 8/8 on transcription, so **the expected values are the table's
  and not re-derived from the implementation**. Seven findings, verdict "ship
  after findings 1 and 2".
- **Findings 1 and 2 accepted: the package held two notions of "the same
  key".** Duplicate detection used `strings.ToLower`, which is *weaker* than
  the `encoding/json` case-insensitive matching A0-2.5's own rationale cites —
  `{"s":1,"ſ":2}` (U+017F) was accepted, yet `json.Unmarshal` of `{"ſ":7}`
  into a struct tagged `json:"s"` matches the field, i.e. cjson could emit a
  canonical document a downstream decode reads as one field. And exclusion
  matched byte-exactly while duplicates matched case-insensitively, so
  `Canonical({"Hash":1,"a":2}, "hash")` kept the field the caller excluded —
  an excluded field influencing a digest, which A0-2.12 forbids. Remedy: one
  orbit-minimum `unicode.SimpleFold` helper used at all three key-identity
  sites, folding **both** sides of the exclusion test (folding only the key
  would silently stop excluding `hash` from every A1 event and break the chain).
  Pairwise `EqualFold` was measured and refused: quadratic in the keys of one
  object, 111 ms at 4k keys and ~11 s extrapolated for the ~40k a 1 MiB hostile
  document can carry (adversarial A14); the fold is linear (4.1 → 7.4 ms at 40k)
  and A0-8.1's `^[a-z][a-z0-9_]{0,39}$` keeps every declared contract key on
  the zero-allocation ASCII fast path.
- **Findings 3–7 (nits) dispatched in the same fix lane:** a depth fixture that

## Decisions

- **The vector test is `TestVectorsV1ToV8ByteExact`.** The principal review's
  WP-07 row named `TestVectorsV1ToV7ByteExact`, which predates V8, and A0 §4.1
  says the vectors are *data, not a test id*, so the name is the principal's to
  set. Recorded here because the reviewer looked for the ruling in `adr/` and
  `docs/reviews/` and could not find it: a ruling lives in the session tracker.
- **`With`'s existing-key collision is `errs.Internal`**, matched
  case-insensitively: A1-1.8 and A1-5.7 make this composition platform-only, so
  a collision is a platform defect, not client input, and A0-2.5 already makes
  `hash` and `Hash` the same key.
- **`TestGatingComparisonsAreConstantTime` is a source scan plus behaviour rows,
  never a timing measurement** (DESIGN §8: deterministic tests; a timing
  assertion is flaky and proves nothing on a busy box). The implementer also
  measured that `subtle.ConstantTimeCompare` returns **1** for two empty slices,
  so `DigestEqual` needs an explicit `sha256.Size` width check — the brief's
  "the empty string returns false" was unachievable without it.
- **Simple folding is the ceiling, not a halfway house.** `ß`/`ss` and `ﬁ`/`fi`
  need CaseFolding.txt tables the stdlib does not ship and `strings.EqualFold`
  does not equate either; matching `EqualFold`'s classes exactly is the goal,
  because that is what a downstream `encoding/json` decode uses.
- **`CanonicalValue` maps every `json.Marshal` failure to `validation`**
  (A0-3.1's "canonicalization failure"), with the citation corrected from
  A0-2.6 to A0-2/A0-3.1 so a `chan` field does not send the troubleshooter to
  the integers clause.
- **Errata for a frozen contract go in the PR that already owns that section.**
  Item 18 was ruled during this session but committed to `foundation/ids-timex-caps`,
  with the reason in its commit message and a comment on PR #4.
