# Errata queue — awaiting product-owner rulings (gate H2)

Contract/ADR defects surfaced by pipeline lanes land here, never in a lane
commit. Format per entry: source (WP + report path), the frozen text with
file:line evidence, the recommended ruling, and what blocks until it is
ruled. Ruled entries move into the contract's §6 (or the ADR's erratum
note) via a principal-applied edit, and get struck through here with the
ruling date and commit.

ADR-0022 erratum note, all ruled 2026-10-07 (sessions/2026-10-07-events-graph.md)._
